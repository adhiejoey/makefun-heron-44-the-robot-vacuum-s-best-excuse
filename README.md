A one-line excuse from a robot vacuum for missing a spot, written as a tiny Node program that outputs the line to `entry.txt`. The vacuum's lidar has classified the missed spot as a permanent resident, and — being a law-abiding little machine — it refuses to evict a tenant without a court order. Deadpan, rooted in the vacuum's own world of sensors and maps, and short enough to fit the 140-character gate.

Run it with `node main.ts`; it writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
